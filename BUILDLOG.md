## Where AI was wrong / what I had to fix

1. **Timezone handling.** AI originally stored timezone-aware datetimes; SQLite
   string compares made future slots publish early or never. Fix: store naive
   UTC everywhere (`app/models.py::utcnow`, slot normalization in
   `app/main.py`). This was found by the live demo, not by reading code.
2. **Partial unique index.** First version was a plain UNIQUE on
   `idempotency_key`, which would have hidden retried failures from history
   (you can't record attempt #2 after attempt #1 failed). Switched to
   `(idempotency_key) WHERE status='success'`.
3. **Crash-injection test timeouts.** The worker's `--once` flag and the
   `max_publishes` parameter had to be added for the subprocess test to be
   deterministic; my first version timed out because the worker treated all due
   slots as one batch.
4. **`os._exit` vs logger flush.** Flushing stderr/stdout before exit was
   required for the crash log line to survive in the transcript.
